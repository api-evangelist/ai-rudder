## API Docs
- 鉴权方法 [验证并获取令牌](https://api-docs.airudder.com/api-53949513.md): 获取令牌并将其添加到其他API的请求header中， 令牌的有效时间为24小时，24小时内重新请求会将令牌的有效期再延长24小时。
- Get the Authorization token [Token Authentication and Obtain](https://api-docs.airudder.com/api-44712004.md): Obtain the token and add it to the request header of other APIs. The token is valid for 24 hours, and any re-request made within this period will extend its validity by another 24 hours.
- 催收 > 调用任务相关 API [创建外呼拨打任务](https://api-docs.airudder.com/api-465585365.md): 创建外呼拨打任务
- 催收 > 调用任务相关 API [列出已创建的任务](https://api-docs.airudder.com/api-54087045.md): 通过分页的方式列出任务，任务将以创建时间倒序排列。
- 催收 > 调用任务相关 API [停止一个呼叫任务](https://api-docs.airudder.com/api-54087361.md): 停止一个呼叫任务
- 催收 > 调用任务相关 API [取消指定任务中的某个电话的拨打](https://api-docs.airudder.com/api-53996765.md): 取消指定任务中的某个电话的拨打
- 催收 > 调用任务相关 API [任务结束状态通知](https://api-docs.airudder.com/api-54087615.md): 当任务结束时，主动通知对接方该任务已结束（如果任务被取消，则不会进行回调）。如果此url响应异常，我方会间隔1分钟进行重试，最多5次重试失败后不在进行通知。
- 催收 > 调用任务相关 API [任务电话维度拨打结束状态通知 ](https://api-docs.airudder.com/api-54087801.md): 任务内电话拨打结束时(接通或者完成拨打次数)，不管接通还是未接通，会在完成全部的重拨次数后主动通知对接方该任务的此电话拨打数据。
- 催收 > 调用任务相关 API [获取任务详细信息](https://api-docs.airudder.com/api-54087838.md): 通过TaskID获取任务内电话拨打的详细信息。
- 催收 > 调用任务相关 API [获取单个案件通话录音](https://api-docs.airudder.com/api-54038717.md): 通过TaskID和被叫号码（Callee）来查询通话录音.仅支持最近1个月内的通话。 
- 催收 > 调用任务相关 API [获取任务录音文件 ](https://api-docs.airudder.com/api-54037705.md): 获取对应任务的录音文件（打包mp3）下载地址，服务端保留最近一个月以内的录音。
- 催收 > 调用任务相关 API [获取机器人列表](https://api-docs.airudder.com/api-65077525.md): 获取机器人列表以及机器人信息
- 催收 > 调用任务相关 API [根据callid获取电话信息和录音链接](https://api-docs.airudder.com/api-175046157.md): 根据callid获取电话详情和录音链接，仅支持查询最近3个月的数据
- 催收 > 调用任务相关 API [任务内AI转人工坐席成功时通知](https://api-docs.airudder.com/api-465874847.md): 任务内电话在转人工坐席成功时通知对接方（仅适用于我方系统获取到转人工成功状态的情况）。
